Multi Wallet Lite API

Introduction to Multi Wallet Integration

As the name suggests, using this solution, game players will have multiple wallets at the same time (including wallets at cooperation partner’s platform and AllBet’s platform). Before entering AllBet platform, game players are required to transfer credit into accounts at AllBet platform. After entering AllBet platform, all game players’ records will be processed and managed in AllBet Gaming System.

Cooperation partner do not need to provide any APIs. And cooperation partner can obtain bet records and reports by calling AllBet APIs.

Advantages

  • Cooperation partner can call AllBet’s APIs directly, and do not need to provide any APIs.
  • It's easy and convenient to integrate with AllBet APIs. It generally takes one to three days.

1 API Encryption Mode

1.1 The Description and process of Encryption

download A property ID, DesKey and Md5Key will be provided to the agent from the Allbet platform. For example:
Property ID: starting from 0000001.
DesKey: string encoded with base64, use to encrypt with DES.
Md5Key: string encoded with base64, use to sign message.

Note: Allbet system will not ask for the agent’s secret key while working, please keep it safe. Severe consequence occurs if you lose the property ID and secret key.

The process is as follows:
1. Taking DesKey provided by Allbet as 3DES algorithm key, and encrypt request parameter composed of key-value pairs delimited by &character. And then, encode the result of the previous step. Final result use as the value of "data" parameter.
2. Add MD5Key to the end of result of step 1, then sign it with MD5 algorithm. And then, final result use as the value of "sign" parameter.
3. Set the propertyId parameter value with Property ID provided by Allbet.
4. Submit request with POST or GET method.

Introductions for gameResult

Format of result for Baccarat:
Use two braces with numbers to indicate the result, the first one indicate Player, the second one indicate Banker.

For example: {403,312,-1},{308,311,-1}
Please refer to Appendix: Game Result (gameResult) to find out the meaning of numbers.

Format of result for DragonTiger:
Use two braces with numbers to indicate the result, the first one indicate Dragon, the second one indicate Tiger.
Please refer to Appendix: Game Result (gameResult) to find out the meaning of numbers.
For example: {308},{311}

Format of result for Sicbo(HiLo):
Used three numbers delimited by comma in a brace to indicate the result of Sicbo(HiLo).
For example: {5, 5, 5}

Format of result for Roulette:
Used one number in a brace to indicate the result of Roulette.
For example: {32}

Format of result for Rock Paper Scissors:
Use one group of numbers enclosed in brace to indicate game result. The first number is the result of Gold area, the second number is Silver’s, and the third number is Bronze’s.
For example: "{3,3,2}"
Please refer to Appendix: Game Result (gameResult) to find out the meaning of numbers.

Format of result for BullBull:
Use five braces with numbers to indicate the result, the first one indicate First Card, the second one indicate Banker, the third one indicate Player1, the fourth one indicate Player2, the fifth one indicate Player3.
For example:
{403},{308,311,310,401,210},{408,411,410,301,110},{208,211,210,101,109},{302,305,309,201,311}
Please refer to Appendix: Game Result (gameResult) to find out the meaning of numbers.

Format of result for Win Three Cards / Three Pictures / Teen Patti 20-20:
Use two braces with numbers to indicate the result, the first one indicate Dragon, the second one indicate Phoenix.
For example: {308,311,310},{401,309,410}
Please refer to Appendix: Game Result (gameResult) to find out the meaning of numbers.

Format of game result for Pok Deng:
Use six groups of numbers enclosed in braces to indicate game result. The first pair is banker's result. Group 2 to 6 indicate game results of player 1 to player 5.
For example: {410,204},{306,403},{309,107},{407,305},{211,403},{107,406}
Please refer to Appendix: Game Result (gameResult) to find out the meaning of numbers.
